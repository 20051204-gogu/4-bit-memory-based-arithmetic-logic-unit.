# 4-bit-memory-based-arithmetic-logic-unit.
Designed a 4 bit ALU using logic gates , it can perform arithmetic operations like addition and subtraction and Has a 4 bit RAM used to store data and transfer the data to input registers of ALU. Through this project i learned the use of logic gates and fundamentals of digital electronics like Latches, Flip-flops, Registers, BUS logic, Clock etc.
